Target Architecture

The environment consists of Airflow, PostgreSQL, Redis and monitoring components.

Component Role Port
Airflow Scheduler Workflow Scheduling 8080
PostgreSQL Metadata Database 5432
Redis Broker 6379

Requirements

INFO
All servers must have network access to PostgreSQL and Redis.
WARNING
Verify firewall and SELinux policies before deployment.
CRITICAL
Do not store passwords, tokens or secrets directly in code repositories.
TIP
Use a centralized secrets manager whenever possible.

Installation Procedure

Step 1 - Create Virtual Environment

python3 -m venv airflow
source airflow/bin/activate

Step 2 - Install Airflow

pip install apache-airflow

Step 3 - Initialize Database

airflow db migrate

Validation

Run the following commands to verify service status. 

systemctl status airflow-scheduler

systemctl status airflow-api-server

Troubleshooting

Error Root Cause Resolution
Connection Refused Port blocked Review firewall rules
Database Timeout Database unavailable Validate connectivity
Scheduler Failed Service stopped Restart service
